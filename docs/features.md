# 功能说明

## 1. 源代码工作区

- 支持选择 `.py` 文件、拖拽上传、粘贴代码和加载内置示例。
- 源代码区始终展开，不提供折叠，避免隐藏核心输入。
- 内置示例为只读，可分析、运行终端和调用追踪，但不能在工作台中修改。
- 支持编辑、保存、取消、复制、重载和清空。
- 代码区使用行号分隔线和轻量编辑器布局。

## 2. AST 结构分析

- 提取类、函数、嵌套作用域和完整的函数签名。
- 支持类型注解、默认值、位置参数、仅位置参数、仅关键字参数、`*args` 和 `**kwargs`。
- 函数签名为折叠列表，所有函数名称和签名始终可见，展开后查看参数详情。
- AST 图展示节点类型和字段关系。

## 3. 性能分析

- 用户代码在独立子进程中运行。
- 使用 cProfile 和 tracemalloc 收集函数耗时与内存信息。
- 使用 PyInstrument 生成原生性能火焰图。
- 自适应采样：无导入代码使用 `200µs`，含导入代码使用 `500µs`；渲染前最多保留 2000 个样本。
- 默认执行超时由 `DEEPTRACER_EXECUTION_TIMEOUT_SECONDS` 控制。

## 4. Python Tutor

- 展示逐行执行、调用栈和变量变化。
- 只有用户主动点击“生成执行流程”时才会再次执行代码。

## 5. 运行终端

- 在“运行观察”中切换到“运行终端”。
- 不触发 AST、PyInstrument、LangGraph 或 Agent。
- 返回 stdout、stderr、异常、traceback、耗时和退出码。
- 每次运行都在独立子进程中执行，有独立超时。
- 不支持交互式 stdin 输入。

## 6. Tracer 函数调用追踪

- 分析后可选择任意数量的函数。
- 所有函数会一次列出，函数列表没有内部滚动。
- 支持耗时统计、彩色终端输出、异常追踪与局部变量记录。
- 查看美化的调用树或原始终端输出。
- 调用树支持逐节点折叠和全部展开/收起。
- Web 端不生成日志文件；`logging_path` 只作为 Tracer 库能力在 API 文档中说明。

## 7. 优化建议与 AI 答疑

- 本地规则建议不依赖模型。
- Agent 开启时可通过 OpenAI 兼容接口增强解释。
- Agent 关闭时不创建模型客户端，也不发送网络请求。
- 分析详情、优化建议和 Tracer 设置支持整块折叠。
- 分析、AST 可视化和 AI 答疑使用分页工作区切换，一次展示一个页面。

## 8. 内置示例

示例代码位于前端 `sampleCode`，包含：

- 8 个函数。
- 位置参数、仅关键字参数和默认值。
- `**overrides`。
- 多层函数调用。
- 递归调用。
- 循环、字典和热点分析。
- 可直接运行的主程序。

## 9. NetBrick 深度学习

DeepTracer 首页提供 NetBrick 入口，在同一 Web 服务中打开：

```text
http://127.0.0.1:8000/netbrick/
```

NetBrick 提供：

- 可视化拖拽神经网络结构。
- 多输入、多输出、并行分支和控制流。
- Tensor Shape 与数据类型推演。
- PyTorch/Paddle 代码生成。
- 复合模块、课件包和结构追踪。

NetBrick 只做结构教学和代码生成，不安装、执行或训练真实的 PyTorch/Paddle 模型。详细说明见 `NetBrick/doc/`。
