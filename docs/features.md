# 功能说明

## 1. 源代码工作区

- 支持选择 `.py` 文件、拖拽上传、粘贴代码和加载内置示例。
- 源代码区始终展开，不提供折叠，避免隐藏核心输入。
- 内置示例以临时副本载入，可以编辑、生成 Patch、分析、运行终端和调用追踪。
- 重新载入内置示例或刷新页面时恢复原始示范代码，不写入浏览器持久化存储。
- 支持编辑、保存、取消、复制、重载和清空。
- 代码区使用行号分隔线和轻量编辑器布局。

## 2. AST 结构分析

- 提取类、函数、嵌套作用域和完整的函数签名。
- 支持类型注解、默认值、位置参数、仅位置参数、仅关键字参数、`*args` 和 `**kwargs`。
- 函数签名为折叠列表，所有函数名称和签名始终可见，展开后查看参数详情。
- AST 图展示节点类型和字段关系。

## 3. 性能分析

- 用户代码在独立子进程中运行。
- 使用 cProfile 和 tracemalloc 收集函数耗时与内存信息。
- 使用 PyInstrument 生成原生性能火焰图。
- 自适应采样：无导入代码使用 `200µs`，含导入代码使用 `500µs`；渲染前最多保留 2000 个样本。
- 默认执行超时由 `DEEPTRACER_EXECUTION_TIMEOUT_SECONDS` 控制。

## 4. Python Tutor

- 展示逐行执行、调用栈和变量变化。
- 只有用户主动点击“生成执行流程”时才会再次执行代码。

## 5. 运行终端

- 在“运行观察”中切换到“运行终端”。
- 不触发 AST、PyInstrument、LangGraph 或 Agent。
- 返回 stdout、stderr、异常、traceback、耗时和退出码。
- 每次运行都在独立子进程中执行，有独立超时。
- 不支持交互式 stdin 输入。

## 6. Tracer 函数调用追踪

- 分析后可选择任意数量的函数。
- 所有函数会一次列出，函数列表没有内部滚动。
- 支持耗时统计、彩色终端输出、异常追踪与局部变量记录。
- 查看美化的调用树或原始终端输出。
- 调用树支持逐节点折叠和全部展开/收起。
- Web 端不生成日志文件；`logging_path` 只作为 Tracer 库能力在 API 文档中说明。

## 7. 优化建议与 AI 答疑

- 本地规则建议不依赖模型。
- Agent 开启时可通过 OpenAI 兼容接口增强解释。
- Agent 关闭时不创建模型客户端，也不发送网络请求。
- 分析详情、优化建议和 Tracer 设置支持整块折叠。
- 分析、AST 可视化和 AI 答疑使用分页工作区切换，一次展示一个页面。

## 8. 可验证修改闭环

- 建议可以生成结构化 Patch，包含源码哈希、精确行范围、原代码校验和替换内容。
- 简单规则修复在 Agent 关闭时仍可生成；复杂语义重构必须由模型生成候选方案，不能伪造可应用 Patch。
- Patch 必须经过基线与语法校验后才能应用，失败时不会部分写入。
- 应用后自动运行修改前后两份代码，比较退出状态、stdout、stderr 和耗时。
- 修改页支持统一 Diff、并排 Diff、点击展开上下文、一键回滚和恢复原分析快照。
- 浏览器上传文件没有项目绝对路径，因此自动验证明确标记为 smoke test，不冒充项目测试。

## 9. 源码定位联动

- 所有分析结果使用统一 `SourceRef`，包含文件、源码哈希和行范围。
- 建议锚点、函数签名、性能热点、AST 节点和 Tracer 节点都可以定位到源码。
- Python Tutor 步进时同步高亮当前源码行，并在调用树中选中包含该行范围的节点。
- 代码修改后旧 `SourceRef` 会失效，避免用旧行号定位新代码。

## 10. 内置示例

示例代码位于前端 `sampleCode`。载入后是可编辑的临时测试副本；点击“重载”恢复原始示例，刷新或重新打开页面也不会保留副本修改。

示例包含：

- 8 个函数。
- 位置参数、仅关键字参数和默认值。
- `**overrides`。
- 多层函数调用。
- 递归调用。
- 循环、字典和热点分析。
- 可直接运行的主程序。

## 11. NetBrick 深度学习

DeepTracer 首页提供 NetBrick 入口，在同一 Web 服务中打开：

```text
http://127.0.0.1:8000/netbrick/
```

NetBrick 提供：

- 可视化拖拽神经网络结构。
- 多输入、多输出、并行分支和控制流。
- Tensor Shape 与数据类型推演。
- PyTorch/Paddle 代码生成。
- 复合模块、课件包和结构追踪。

NetBrick 只做结构教学和代码生成，不安装、执行或训练真实的 PyTorch/Paddle 模型。详细说明见 `NetBrick/doc/`。

## 12. Turtle 绘图学习

首页提供 Turtle 入口，打开独立的 `/turtle/` 工作台：

- 点击画布后使用方向键向上下左右移动，`Q`/`E` 原地转向；`Shift` 组合或 `-`/`+`、`[`/`]` 可调整长度与角度，并实时显示数值。`Esc` 可从编辑区返回画布。
- 学生代码与标准 `turtle` 代码并排显示，绘图逻辑封装在 `draw_scene(artist, screen)` 函数中，并由 `main()` 调用；两区支持双向悬浮联动、下一步、继续/暂停、断点、速度切换和一键全速。
- 执行时同步显示当前行、长度、朝向、画笔状态、作用域变量和函数调用栈；绘图视口会根据完整轨迹自动缩放。
- 错误会翻译成适合初学者的语法错误或运行错误，并定位到对应源码行；图形不符预期时由任务反馈按移动次数、闭合、边长和角度进行逻辑评测。
- 内置线条、正多边形、五角星、螺旋、分支、函数和重构任务，提供概念、结构、片段三层提示及可关闭的概念旁白。
- 支持画笔颜色、粗细、填充和轨迹开关，并可生成方向键与鼠标点击事件版标准代码。
- 作品保存在浏览器本地，可恢复、导出 PNG 和标准 Python 源码。
- 海龟指示、图标和画布全部由本项目 Canvas/CSS 自行绘制，不包含参考项目的图片资源。

页面实现、代码生成逻辑和视觉资产均为 DeepTracer 自有实现，不引入第三方海龟图片资源。
