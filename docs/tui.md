# 终端菜单

DeepTracer 只注册一个终端命令：

```bash
deeptracer
```

运行后会打开 Rich 终端主菜单。界面使用方向键导航，并根据当前终端的宽高自动切换完整或紧凑布局；拉动终端窗口后会实时重排。布局会预留终端最后一行，避免部分终端裁掉底部内容。菜单不绘制分组横线或边框，只用留白、字重和当前项的蓝色高亮区分层级。Rich 不可用时自动回退到 ANSI 菜单。

如果终端高度连九个菜单项都无法容纳，界面会提示放大窗口，而不会显示残缺菜单。菜单只在按键或终端尺寸变化时重绘，不会在空闲时反复向终端输出画面。

快捷键：

- `Up` / `Down`：移动选项
- `Home` / `End`：跳到首项或末项
- `Enter`：执行
- `Esc` / `Q` / `Ctrl+C`：退出

## 菜单功能

| 编号 | 功能 |
| --- | --- |
| 1 | 启动 DeepTracer Web，显示访问地址但不自动打开浏览器 |
| 2 | 配置模型 API |
| 3 | 启用 Agent |
| 4 | 关闭 Agent |
| 5 | 查看当前脱敏配置 |
| 6 | 快速分析 Python 文件 |
| 7 | 显示 API 文档地址 |
| 8 | 查看项目信息 |
| 0 | 退出 |

## Web 工作台

菜单选择“启动 DeepTracer Web”后：

- DeepTracer：`http://127.0.0.1:8000/`
- NetBrick：`http://127.0.0.1:8000/netbrick/`
- API 文档：`http://127.0.0.1:8000/api-docs`

按 `Ctrl+C` 停止 Web 服务并返回终端菜单。

## 配置文件

模型和 Agent 配置固定保存在：

```text
~/.deeptracer/.env.local
```

终端菜单不会在“查看配置”中显示完整 API Key，只显示脱敏值。
