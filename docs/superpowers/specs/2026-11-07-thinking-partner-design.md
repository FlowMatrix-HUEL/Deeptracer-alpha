# 思辨伙伴（Thinking Partner）设计

## 定位

AI 不是老师、不是助教、不是代码生成器，而是一个和学生坐在同一侧的**共思者**：

> 你带着困惑来，伙伴陪你把它变成一个可以验证的问题。

- 伙伴不拥有答案，也不拥有议程。
- 伙伴拥有的是：提问、假设、示范、验证的质量。
- 事实由确定性工具提供：运行、Trace、Shape、编译、Patch 校验。

## 入口

首页有一个终端风格输入框：

```text
~/deeptracer $ deeptracer▌
```

输入 `deeptracer` 后播放短启动序列，进入工作台并打开伙伴；也支持 `turtle` / `netbrick` / `python` / `help`。保留“直接进入”链接，入口不是门槛。

三个工作台底部各有一条**折叠的命令行**：

```text
~/deeptracer $ 输入 deeptracer 打开思辨伙伴
```

输入 `deeptracer` 后，在当前页面底部展开终端抽屉（不是新页面、不是新标签页）；按 `Esc` 或点“关闭”收回命令行。伙伴默认不占用页面空间。

## 终端 UI

- 深色中性终端（`#0d0d0f`），无卡片边框、无圆角、无阴影；只有极细的分隔线。
- `⏺` 表示伙伴动作，`⎿` 表示证据/结果，`›` 是用户输入。
- 流式 token；动作、证据、代码提案是文本块，不是卡片。
- 四种模式以文字形式排列：提问 / 共查 / 反驳 / 复述；当前模式前面一个 `›`。
- 底部状态行：提示级别（H0–H4）、模式、本地记忆。
- 抽屉高度约 52vh，覆盖在当前工作台上；关闭后回到折叠命令行。

## 引导策略（H0–H4）

| 级别 | 伙伴给什么 |
|---|---|
| H0 | 只问，不给内容 |
| H1 | 指向具体行/步/节点 |
| H2 | 最小反例或最小变体 |
| H3 | 带空的最小示范代码 |
| H4 | 完整答案，明确标注，且只在学生连续坚持后出现 |

- 第一轮只能是 H0/H1。
- 每个 H2/H3/H4 必须挂一个可点击的验证动作。
- 代码提案永远先经过 diff 预览，用户确认后才插入。

## 代码提案与插入

伙伴在正文后输出动作块：

```text
[ACTION]{"kind":"propose_code","target":{"workbench":"python","mode":"insert","line":4},"code":"...","why":"...","hintLevel":"H3"}[/ACTION]
[HINT]H3[/HINT]
```

- Python：插入到编辑器指定行，进入编辑模式，用户保存后重新分析验证。
- Turtle：插入到简化源码指定行，自动编译验证。
- NetBrick：v1 显示示范代码并支持复制；图节点级插入留到下一版。

## 流式协议

`POST /api/partner/stream`，SSE：

- `meta`：工作台、模式、模型运行时、记忆目录、最近档案。
- `token`：正文增量。
- `action`：evidence / highlight / jump / run / propose_code / save_case。
- `hint`：当前 H 级别。
- `done`：本轮结束。
- `error`：生成或连接失败。

服务端先流式输出正文；动作与提示块放在正文之后，由服务端解析并作为结构化事件发送。客户端有 45 秒超时保护。

## 长期记忆（文件系统）

```text
~/.deeptracer/partner/
  profile.json          # 偏好模式、最近提示级别
  index.json            # 档案索引
  cases/<id>.json       # 每次困惑调查的完整档案
  threads/YYYY-MM-DD.jsonl  # 追加式对话事件
```

- 原子写入（临时文件 + `os.replace`）。
- 无数据库；用户可直接打开、备份、清空。
- 会话开始时只读取最近 3 个相关档案 + 未解决概念 + profile，拼成紧凑上下文。
- 前端“保存”把最近一轮保存为档案；“记忆”列出档案与结论。

## 三端接入

- **Python**：代码、分析摘要、最近 Tutor 步；动作跳转源码行/步骤；插入代码。
- **Turtle**：简化源码、最近执行步、错误、程序特征；动作跳步/高亮行/插入源码。
- **NetBrick**：图摘要、结构追踪、诊断；动作选中节点/跳步；示范代码复制。

## 非目标

- 不自动执行动作；运行/插入/保存都由用户确认。
- 不在第一版做 NetBrick 图节点级自动插入。
- 不把完整对话历史塞进模型；只给最近 10 条消息 + 紧凑记忆。
- 不在无模型时伪装成模型；本地保底会明确标注“未配置模型”。
