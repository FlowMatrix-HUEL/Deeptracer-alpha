# 复合资源

复合资源是 NetBrick 中可复用的小网络。它不是简单的节点分组，而是带完整输入输出接口、内部结构、参数和版本的独立资源。

## 发布

满足以下条件时，当前网络可以点击“发布为复合模块”：

- 图结构通过校验。
- 至少包含一个 Input 和一个 Output。
- 嵌套复合与控制容器不超过 3 层。
- 不存在复合资源依赖环。

发布后：

- 资源获得稳定 `resource_id`。
- 第一次发布版本为 `v1`。
- 输入端口自动来自 Input 节点。
- 输出端口自动来自 Output 节点。
- 所有内部模块、控制容器和嵌套复合参数递归进入参数目录。

## 模块库

左侧“复合模型”分组显示每个资源的最新版本：

- 点击或拖入画布会创建一个复合实例节点。
- 新实例默认使用最新版本。
- 卡片的下载按钮导出 `.netbrick-module.json`。
- 卡片删除按钮会移除该资源在本地模块库中的所有版本；已有工程内嵌快照不受影响。
- “导入 .netbrick-module.json”可将资源加入本地库。

资源定义保存在浏览器 IndexedDB；父工程 IR 内嵌实际使用的资源快照，因此离线打开工程不会丢失依赖。

## 实例与版本

复合节点固定引用 `resource_id + revision`。

- 旧实例不会自动升级。
- Inspector 可以选择同一资源的其他版本。
- 切换版本时保留类型仍兼容的参数覆盖，丢弃不兼容路径。
- 修改实例参数只影响该实例。

## 参数覆盖

复合资源默认参数使用层级路径：

```text
left_linear.out_features
control_1/predicate/compare.operator
nested_block/child_layer.kernel_size
```

父模型通过参数覆盖改变内部参数，Shape 会重新推演。若输出 Shape 改变导致父图连线冲突，错误会显示在问题面板。

## 内部结构下钻

双击复合节点进入中间画布的只读子图：

- 画布显示面包屑和“只读”标记。
- 可以查看内部节点、端口、Shape 和生成代码。
- 不能直接修改已发布版本。
- 点击“编辑新版本”复制资源并自动生成下一整数版本草稿。
- 保存草稿后新版本进入资源库；旧实例仍引用旧版本。

## 代码生成

每个实际使用的复合实例生成独立命名模块类：

```python
class MyBlockV1Model(nn.Module):
    ...

class ParentModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.block = MyBlockV1Model()
```

复合类内部再次引用其他复合资源时，依赖类会一并写入同一个 Python 文件。

## 旧 Mojo

旧版 Mojo 只保存任意节点片段，并不保证具有完整 Input/Output。它们继续作为 Legacy 入口保留，但不会被误认为可独立调用的复合模块。
