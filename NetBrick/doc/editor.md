# 编辑器与交互

## 顶部导航

- 左侧：NetBrick 标识、PyTorch/Paddle 框架下拉框、项目名称。
- 中部：当前数据流数量和结构状态。
- 右侧：新建、导入 JSON、保存/导出、载入示例、撤销重做、结构追踪和导出代码。

框架下拉框的选项为：

- `PyTorch 模式`
- `PaddlePaddle 模式`

切换框架后，模块库、画布节点、Inspector 参数和 Python 预览都会同步更新。

## 模块库

模块库按功能分组，条目采用无框列表：

- 分组可以点击折叠或展开。
- 搜索支持分组名、官方类名、API 路径和内部算子名。
- 点击条目会把节点加入画布。
- 拖拽条目可以在指定画布位置创建节点。
- 条目显示当前框架的官方类名和完整 API 路径。

损失函数和优化器显示为训练阶段入口，不进入当前推理数据流。

## 画布

### 节点

- Input/Output 表示模型边界。
- 普通层有一个 Tensor 输入端口 `x` 和一个输出端口 `out`。
- `Add`、`Multiply`、`Concat` 使用一个聚合输入端口 `x`，该端口可以连接任意多个上游输出。
- 节点显示当前框架官方类名、关键参数和输出 Shape。

### 连线

- 连线只能从 `out` 连接到合法输入端口。
- 一个输出可以连接多个下游节点，从而创建并行分支。
- 普通节点的一个输入端口只接收一条线。
- 合并节点的 `x` 端口可以接收两条或更多输入线。
- 双击连线可以删除。
- 悬停在连线上会显示该数据流的 Shape。

### 并行与合并

并行结构通常按以下方式搭建：

1. 从同一个上游节点拉出多条连线。
2. 让每条分支经过不同的网络层。
3. 将分支输出连接到同一个 `Add`、`Multiply` 或 `Concat` 的 `x` 端口。
4. 将合并结果继续连接到后续层或 Output。

合并端口不限制固定输入数量，但至少需要连接两个上游节点。

### 画布操作

- 滚轮缩放，右键拖动平移。
- 右下角控件支持缩小、放大、百分比显示和适应画布。
- 左侧拖动框或多选后按住 Shift 点击可选择多个节点。
- 右键菜单支持删除、复制、粘贴、清空画布和打包 Mojo。
- 双击复合节点进入只读内部画布，可创建新版本。
- 双击控制容器查看谓词、分支或循环体，并通过面包屑切换区域。
- 节点和连线校验失败时使用红色错误反馈。

## 右侧 Inspector

- 未选择节点时显示工程概览、节点/连线/数据流/错误统计、工程信息和教学提示。
- 选择节点后自动切换为参数编辑。
- 参数名显示当前框架官方参数名。
- 会隐藏当前框架不支持的参数项。
- 合并节点会同时显示所有输入 Shape 和输出 Shape。

## 底部面板

- `问题`：显示结构、端口、参数和 Shape 诊断。
- `Python`：自动生成并显示当前框架源码，支持复制和下载。
- 点击“导出代码”或代码面板的下载按钮时，Chromium/Edge 会打开系统“另存为”文件选择器；其他浏览器回退到默认下载目录。
- 如果浏览器不支持文件系统选择器，NetBrick 会调用本机后端 `zenity` 打开系统原生保存对话框；两者都不可用时才回退浏览器下载。
- `结构追踪`：按拓扑顺序展示每个节点的输入 Shape、输出 Shape 和 dtype。

底部面板可以上下拖动调整高度，也可以收起。

## 布局

- 左侧模块库和右侧 Inspector 可以独立折叠。
- 两侧面板均可拖动边缘调整宽度。
- 中间画布、右侧检查和底部面板共同构成课堂工作区。
- 本地文件是工程的主要持久化方式，不使用数据库。
