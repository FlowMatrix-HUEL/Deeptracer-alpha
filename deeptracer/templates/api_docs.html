API 概览

DeepTracer 的接口分为原生 HTTP API 与内置库 API。左侧每个条目都是当前页面内的一页，点击后只更新右侧内容。

当前模块

  • DeepTracer 主库：代码运行、分析、调用追踪、Python Tutor 和答疑。
  • Tracer 内置库：装饰器与上下文管理器。
  • 扩展：未来原生 API 的命名、路径和安全约定。

接口约定

  • 原生接口统一使用 /api/*。
  • JSON 请求使用 Content-Type: application/json。
  • 执行用户代码的接口使用独立子进程和超时。
  • 错误以 FastAPI detail 字段返回。
POST /api/run

运行代码

在独立子进程中执行 Python 代码，返回标准输出、错误输出、异常和耗时。

请求参数

字段类型必填说明
codestring是需要执行的 Python 代码。
 
{
  "code": "print('hello')"
}

响应字段

{
  "durationMs": 1.2,
  "stdout": "hello\n",
  "stderr": "",
  "runtimeError": null,
  "traceback": "",
  "exitCode": 0
}

超时返回 HTTP 504；代码语法错误返回 HTTP 400。

POST /api/analyze

代码分析

执行 AST、函数签名、性能、内存和可选的 Agent 分析。

请求参数

字段类型说明
codestringPython 源代码。
pathstring可选文件路径。
displayNamestring前端显示名称。
taskIdstring可选任务 ID，用于答疑上下文。
analysisobject已有分析快照。

响应

返回 heroMetrics、analysisMap、suggestions、visualizations、runtimeBanner 和 meta。Agent 关闭时使用本地结果。

POST /api/tracer/trace

函数调用追踪

执行代码并追踪指定函数，返回结构化调用树和终端输出。

请求

{
  "code": "def add(x, y): ...",
  "functions": ["add"],
  "options": {
    "timeTrace": true,
    "useColor": true,
    "exceptionTrace": false,
    "showLocals": false
  }
}

响应

  • traceTree：函数调用层级。
  • terminalOutput：Tracer 终端输出，包含 ANSI 颜色。
  • statistics：调用次数、总耗时、平均耗时、最小和最大耗时。
  • errors：异常追踪记录。
  • runtimeError：用户代码异常。
POST /api/tutor/trace

Python Tutor 执行轨迹

生成 Python Tutor 前端可渲染的逐步执行数据。

请求

{
  "code": "x = 1\nprint(x)",
  "rawInput": [],
  "options": {}
}

成功时返回 code 和 trace。

GET /api/tutor/status

Python Tutor 状态

检查本地 Python Tutor 静态运行环境是否可用。

响应

{
  "available": true,
  "embedUrl": "/tutor/iframe-embed.html"
}
POST /api/chat/stream

流式答疑

基于当前代码、分析摘要和代码锚点生成 SSE 流式回答。

请求

{
  "code": "...",
  "displayName": "demo.py",
  "taskId": "task-id",
  "messages": [
    {"role": "user", "content": "为什么这个函数先执行？"}
  ]
}

事件

返回 text/event-stream，包含 meta、chunk、done 或 error 事件。

LIB Tracer

Tracer 库概览

当前内置的轻量级 Python 函数调用追踪库。

导入

from deeptracer import Tracer, tracer

# 或
from deeptracer.tracing import Tracer, tracer

# 被 DeepTracer 执行的代码
from tracer import Tracer, tracer

能力

  • 函数调用与返回层级。
  • 参数和返回值。
  • 调用次数与耗时。
  • 异常传播与局部变量。
  • ANSI 终端颜色。
LIB tracer

tracer 装饰器

追踪被装饰函数以及 trace_fn 中指定的函数。

示例

@tracer(
    trace_fn=[func_a, func_b],
    trace_entity=True,
    time_trace=True,
    use_color=True,
)
def entrypoint():
    ...

参数

参数默认值说明
trace_fnNone额外追踪函数。
trace_entityFalse追踪被装饰函数。
time_traceFalse耗时统计。
use_colorFalse终端颜色。
exception_traceFalse异常追踪。
show_localsFalse异常局部变量。
logging_pathNoneTracer 库参数；DeepTracer Web 不生成日志。
interactiveFalse交互 Shell，Web 端关闭。
interactive_on_eventFalse事件级交互，Web 端关闭。
LIB Tracer

Tracer 上下文管理器

在代码块范围内追踪指定函数。

示例

with Tracer(
    trace_fn=[add, recursive_count],
    time_trace=True,
) as trace_context:
    main()

statistics = trace_context.stats.data
errors = trace_context.errors.to_list()

说明

支持 trace_fn、time_trace、use_color、exception_trace、show_locals 等参数。上下文管理器不支持 trace_entity。Tracer 本身支持 logging_path，但 DeepTracer Web 不生成日志。

DEV Extension

扩展约定

未来新增原生 API 时，继续在当前 API 文档树中加入页面。

约定

  • 原生 HTTP 接口统一位于 /api/*。
  • 每个 API 在左侧主库分组下增加一个页面按钮。
  • 当前页面内切换内容，不新增独立文档路由。
  • 执行用户代码必须使用独立子进程与超时。
  • 新增页面必须描述参数、请求、响应和错误。
